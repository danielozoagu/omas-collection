=====================================================
          OMAS COLLECTION - ADMIN DESKTOP APP
=====================================================

HOW TO RUN:
1. Double-click "OmasAdminApp.exe" to launch the desktop application.

HOW TO OPEN IN VISUAL STUDIO:
1. When Visual Studio finishes installing, double-click "OmasAdminApp.sln".
2. You can edit the C# code, design the XAML UI, and press F5 to run and debug.
3. To publish anytime: right-click OmasAdminApp in Solution Explorer -> "Publish".

DEFAULT LOGIN CREDENTIALS:
- Server URL:  http://localhost/OMAS-COLLECTION-BACKEND
- Email:       admin@omas.com (or admin@omascollection.com / admin@oamscollection.com)
- Password:    admin123

DATABASE & DATA SYNC:
- Users registered on the Web App appear automatically in the "Customers" tab.
- Orders placed on the Web App appear in the "Orders" tab.
- Products added/edited in this app update instantly on the Web App.
